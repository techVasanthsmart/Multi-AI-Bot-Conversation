# Multi-AI Conversation 🌌

A next-generation UI for defining AI personalities and simulating chaotic conversations. Built entirely with **Next.js**, **Tailwind CSS**, and **Framer Motion**.

## 🚀 Getting Started

### Prerequisites

- Node.js 18+ installed

### Installation

1. Clone the repository and navigate to the project directory.

2. Install dependencies:
   ```bash
   npm install
   ```

3. Configure your API keys by creating a `.env` file (you can use `.env.example` as a template):
   ```bash
   cp .env.example .env
   ```
   Add your keys (e.g., `OPENAI_API_KEY`) to the `.env` file.

4. Start the development server:
   ```bash
   npm run dev
   ```

5. Open [http://localhost:3000](http://localhost:3000) in your browser.

## ✨ Features

- **Character Studio**: Define unique AI personalities with custom names, models, and traits.
- **Frontend-Only Architecture**: A seamless, unified codebase built entirely in Next.js without needing a separate backend service.
- **Modern Light Theme**: A clean, bright design with sleek UI components and an updated custom favicon.
- **Chat Interface**: A simulated chat environment to preview how your bots dynamically interact based on their personas.

## 🛠 Tech Stack

- **Framework**: Next.js (App Router)
- **Styling**: Tailwind CSS, Shadcn UI elements
- **Icons**: Lucide React
- **Animations**: CSS Keyframes & Framer Motion
- **AI Integration**: OpenAI SDK

## 📝 Usage

1. **Add Characters**: Use the setup form to define at least 2 distinct AI characters.
2. **Set Topic**: Enter an initial topic or context for their discussion.
3. **Start Simulation**: Click "Start Simulation" to initiate the conversation.
4. **Observe & Control**: Watch the chaotic interaction unfold, with options to pause, reset, or go back to setup anytime.
